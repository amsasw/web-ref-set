# 风格集 STYLEKIT

> 一个用于网站设计灵感探索的多风格动态网页聚合库。通过浏览、筛选和预览不同的网页视觉方案，为后续网站设计提供参考。

## 1. 项目简介

**风格集（STYLEKIT）** 是一个轻量级网页设计灵感库，旨在把不同风格的网页方案集中到一个可浏览、可比较的页面中。

当前版本以独立 HTML 文件实现，不依赖框架或第三方运行时。用户可以在浏览器中打开页面，查看不同风格的预览、筛选设计方向、收藏喜欢的方案，并查看相应的设计说明与配色变量。

## 2. 当前功能

- **多风格展示**：内置 12 种风格方向，包括现代简约、深色科技、自然清新、商务专业、创意艺术、极简黑白、复古怀旧、动态视觉、旅行探索、电商购物、个人博客和知识文库。
- **分类筛选**：按风格类别浏览方案。
- **关键词搜索**：搜索风格名称、描述、关键词和适用场景。
- **收藏方案**：标记喜欢的设计；可切换为只看收藏。
- **动态预览**：通过预览弹窗查看页面标题、介绍和视觉主题。
- **设计要点**：查看风格说明、适用场景、设计关键词。
- **配色参考**：查看配色样本和 CSS 自定义属性，并尝试复制配色代码。
- **响应式布局**：适配常见桌面浏览器和移动屏幕。
- **无需构建**：当前版本为单文件 HTML，打开即可使用。

## 3. 固定主题实验：清序 · 薄荷牙膏

新增 `toothpaste_theme_demo.html`，作为 Issue #2 的第一版交互原型。它将同一份虚构产品内容呈现为四种风格：自然清新、复古艺术、年轻活力和深色科技。

- 支持单页预览、双栏对比和四风格总览。
- 固定产品文案、区块顺序、包装示意、规格与价格，重点比较视觉语言。
- 包含产品首屏、产品细节提示、卖点、日常使用场景、数量调整与演示购物袋反馈。
- 根据风格切换配色、字体、圆角、边框、阴影、间距和组件气质。
- 使用原生 HTML、CSS 和 JavaScript，无需安装依赖；产品图目前为 CSS 包装示意，不是实拍素材。

打开 [牙膏主题风格对比原型](./toothpaste_theme_demo.html) 即可体验。购买操作仅展示演示反馈，不会创建真实订单。

## 4. 如何运行

### 方法一：直接打开

1. 下载或克隆项目文件。
2. 找到 `stylekit_website_gallery.html`。
3. 使用 Chrome、Microsoft Edge 或其他现代浏览器打开。

无需安装 Node.js、无需执行 `npm install`，也无需启动开发服务器。

### 方法二：使用本地静态服务器（可选）

在项目目录中执行：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/stylekit_website_gallery.html`。

## 6. 使用方式

1. 打开页面，浏览全部风格卡片。
2. 使用分类按钮或搜索框缩小范围。
3. 点击“打开动态预览”查看方案。
4. 点击“设计要点”查看风格说明、适用场景和配色。
5. 点击爱心图标收藏方案。
6. 在收藏视图中集中比较喜欢的方案。
7. 复制 CSS 配色变量，将其作为新项目的配色起点。

> 当前预览是用于表达设计方向的示例页面，并非每一种风格都对应一个独立完整的网站。当前版本也不是可视化网站构建器。

## 7. 设计理念

本项目围绕以下流程组织：

**发现灵感 → 筛选风格 → 预览方案 → 拆解设计 → 复用到新项目**

设计方案可以从以下维度拆解：

- 色彩：页面背景、强调色、文字色和卡片色。
- 排版：标题层级、正文宽度、留白和对齐方式。
- 布局：导航、首屏、内容区、卡片网格和页脚。
- 交互：悬停反馈、按钮状态、弹窗和筛选。
- 适用场景：企业官网、作品集、产品页、博客、电商和文档站等。

## 8. 已知限制

- 当前是静态前端演示，没有后端服务或用户账户系统。
- 收藏状态目前只保存在当前页面运行状态中；刷新页面后不保证保留。
- 页面中的设计预览是演示性布局，不等同于完整的真实网站模板。
- 复制配色功能依赖浏览器剪贴板权限；在部分受限环境下可能无法直接复制。
- 当前版本没有自动导出完整网站项目、在线编辑布局或保存自定义模板的能力。

## 9. 后续开发规划

### 第一阶段：体验完善
- 为每种风格提供更丰富的预览内容。
- 增加桌面、平板和手机预览尺寸切换。
- 加入颜色、布局、动效类型和使用场景筛选。
- 改善键盘操作、对比度和移动端交互。

### 第二阶段：组件拆选
- 将页面拆成可单独预览的导航栏、按钮、卡片、表单、页脚和布局组件。
- 为组件提供不同变体与状态。
- 支持组合多个组件，形成一套页面方案。

### 第三阶段：编辑与导出
- 在线编辑文案、颜色、字体、间距和圆角。
- 导出可复用的 HTML、CSS 或组件代码。
- 保存自定义方案并支持导入、导出配置。

### 第四阶段：项目化
- 将单文件拆分成模块化项目。
- 引入模板数据管理、持久化存储和自动化测试。
- 如确有多人协作或云端同步需求，再评估后端与账户体系。

## 10. 技术说明

当前版本使用 HTML、CSS 和原生 JavaScript 实现页面结构、响应式布局、悬停效果、分类、搜索、收藏、预览弹窗和配色复制。没有使用前端框架或构建工具。

## 11. 修改建议

- **增加风格**：在 HTML 文件的 `styles` 数据数组增加风格数据。
- **增加分类**：更新分类列表，并确认新增类别与风格数据一致。
- **调整视觉效果**：修改卡片、预览区域、网格和响应式 CSS。
- **扩展交互**：在 JavaScript 中添加对应事件和状态处理。
