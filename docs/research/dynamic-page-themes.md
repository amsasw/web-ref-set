# 动效网页的固定主题选型

调研日期：2026-10-17。

## 结论

本项目优先选择「创意设计工作室官网」作为跨风格对比的固定内容主题。依据是本次读取的 Framer Animated 目录前 24 个模板中，17 个以创意设计机构、个人作品集或个人履历为主要用途。统计由下方逐项分类得出。个人作品集也有充分样本支持，但工作室主题更便于同时容纳作品、服务、团队、评价和联系区块；这一取舍是针对本项目的设计建议。

如果需要多个主题，建议增加「SaaS 产品发布页」和「单品展示页」，分别覆盖软件界面演示与商品展示。这是为了扩大可比较的组件与动效范围，不代表它们在全网的出现频率排名。

此前将咖啡品牌列为首选属于题材适配建议；本次样本没有提供将其列为动效案例高频主题的证据。

## 定义与采样方式

- 本次“动态页面”指带滚动动画、悬停、转场、视差或交互展示的网页。
- 样本来自 [Framer Animated 目录](https://www.framer.com/marketplace/templates/categories/animated/)，取本次网页工具首次读取返回的前 24 个条目，保留显示顺序。
- 依据模板作者在官方市场中的标题、用途说明和描述人工归类，每条只计一个主要类别。机构与个人兼用的作品展示模板归入「创意设计机构与个人展示」。
- 这是目录首批条目的便利样本，受到排序、平台受众和模板供给影响，不能推广成全网占比。
- 测量的是「动效目录中各主题出现多少」，没有测量「某一行业全部网站中多少使用动效」。
- 动效特征来自平台归类和作者说明，本次未在浏览器中逐一测试运行表现。
- 未购买、安装或复制任何模板。

## GSAP 案例库交叉检查

读取 [GSAP Showcase](https://gsap.com/showcase/) 及该站公开使用的案例数据接口：`https://gsap.com/community/index.php?app=gspages&module=ajax&controller=api`。

本次取得 500 条案例记录，按 `item_url.full` 字符串去重为 497 个 URL。取得的 JSON 保存为 [gsap-showcase-2026-10-17.json](gsap-showcase-2026-10-17.json)。以下按记录而非去重 URL 统计 `tags` 字段，同一条记录允许有多个标签。

| 官方标签 | 记录数 |
| --- | ---: |
| Scroll Animation | 431 |
| Text Animation | 387 |
| Web GL | 230 |
| SVG Animation | 165 |
| Portfolio | 76 |
| UI Interactions | 43 |

此数据能证明在这批 GSAP 精选案例中，滚动与文字动效标签大量出现。其标签主要按技术与表现分类，没有覆盖全部行业的互斥主题分类，因此不能据此给 SaaS、餐饮、电商等行业排名，也不能把没有行业标签解释为不存在该类网站。Portfolio 标签与人工判断的行业用途也不能直接等同。

## 建议落到本项目的主题

这些名称与内容是设计提案，并非被调研站点。

1. **FORM Studio · 创意设计工作室**：固定品牌介绍、六个项目、三项服务、团队简介、客户评价和联系入口。优先覆盖文字入场、作品悬停、图片揭示、轮播与区块转场。
2. **FlowDesk · 团队协作工具**：固定产品界面、三项功能、操作流程、套餐和 FAQ。覆盖功能切换、界面演示、计数和价格切换。
3. **AURA · 无线耳机产品**：固定产品图片、配色、三项特性、参数与购买入口。覆盖图片轮播、配色切换、滚动特性展示。

只做一个时先选择 FORM Studio；多个主题用于拓宽对比能力，保持每个主题自身的文案、图片、信息层级和组件数量一致。
